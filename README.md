# FiscalAuxiliar – Atualizações

Distribuição dos instaladores do GHAN Fiscal (FiscalAuxiliar).

Cada versão é publicada como uma *release* estável com a tag `v<versão>` (ex.: `v1.1.24`) e o anexo
`GHAN_Setup_<versão>.exe`, gerado pelo Inno Setup. O sistema consulta a última release pelo menu
**Ajuda › Verificar atualização**.

Este repositório não contém código-fonte.
